Automations

Visual flow builder that reacts to events — welcome new contacts, recover carts, route leads and let AI answer — all without code.

The builder

Open Automations from the sidebar and create a new automation. The builder is a canvas: drag nodes from the left palette, connect them into a flow, and configure each node in its panel. Every automation has exactly one trigger (the entry event) followed by any sequence of action nodes.

  • Templates — start from ready-made recipes instead of a blank canvas.
  • Test — dry-run your flow before activating; nothing is sent and no tags are applied.
  • Status — automations only fire while active; pausing stops all runs instantly.

Triggers (when a flow starts)

Form submitteda WhatsApp flow/form is completedBookings, lead capture, surveys
Webhook receivedan external system POSTs to your flow's URLPayment alerts, CRM sync
Order placeda store order comes inOrder confirmations
Order fulfilledan order is shipped/completedTracking + delivery feedback

💡 Keyword filter

On Message received, leave keywords empty to run on every message, or list comma-separated keywords (e.g. menu, price, rates) to run only when one appears in the message.

Personalisation tokens

Drop tokens into any message to personalise it:

TokenBecomes
{{contact.first_name}}Customer's first name
{{contact.name}} · {{contact.email}} · {{contact.phone}}Other contact fields
{{context.campaign_name}}Name of the campaign that fired the flow
{{context.order_number}} · {{context.order_total}}Order details on order triggers
{{context.cart_total}} · {{context.recovery_url}}Cart amount and checkout link
{{context.tag_name}}The tag that was just added
{{message.body}}The customer's inbound message

Popular recipes

1. Welcome flow

Trigger: New contact → Send WhatsApp: “Hi {{contact.first_name}}! 👋 Welcome to our store. Reply MENU to see the catalogue.” → Add tag: welcomed

2. Keyword menu

Trigger: Message received (keywords: menu, price) → Quick replies with buttons Pricing / Services / Talk to human → each button branches to its own message or Assign agent.

3. AI receptionist

Trigger: Message received (no keywords) → Condition: contact has tag human_requested → if yes: Assign agent; if no: AI reply.

4. Cart recovery

Trigger: Cart abandoned → Wait 1 hour → “Your cart holds {{context.cart_total}} — finish here: {{context.recovery_url}}” → Wait 1 day → “Last chance! Coupon CART10 for 10% off.”

5. Post-campaign follow-up

Trigger: Campaign sent → Add tag: received-offer → Wait 3 days → if the customer hasn't replied, send a gentle reminder with a coupon.

⚠️ Avoid loops

Never let a “Tag added” automation add the same tag that triggers it — use a different tag name, or the flow will run forever.

Webhook trigger

Use Webhook received to start a flow from outside tools:

1

In the trigger panel, click Generate Token and copy your unique URL.

2

Point your website, CRM or payment gateway to POST that URL.

3

Include contact_id in the body when possible so the flow runs for that customer.

⚠️ Keep the URL secret

Anyone with the token URL can trigger the flow. Regenerate the token if it leaks.

Testing & monitoring

  • Test button — preview the run without sending anything.
  • Runs page — every execution is logged: which nodes ran, in what order, with what result. Open Automations → Runs.
  • Real-world test — trigger the event for real (message yourself, add a test tag, POST a test webhook) and watch the run appear.
📎 Runs pending?

Automation runs execute on a queue. If runs stay pending or an admin recently deployed, runs process within moments — contact support if runs never start.
