Settings & Developer

Tune your workspace preferences, control notifications, export your data, and integrate with the API.

Account settings

Under Account → Settings you can:

  • Update your profile — name, email, password and avatar.
  • Set workspace defaults — language, currency and timezone used across the app.
  • Manage workspaces if your plan includes more than one (see Workspaces).

Notifications

Account → Notifications controls how the app gets your attention:

  • Choose events worth interrupting for — new inbound message, assignment, campaign completion.
  • Pick channels: in-app notifications and browser push (the first enable asks browser permission).
  • Everything lands in the notifications inbox from the bell icon, regardless of settings.

Data export

Settings → Data Export generates downloadable copies of your workspace data — contacts and conversations — so you always own your information. Request an export and download the file when it's ready.

Audit log

The Audit Log records important changes made in your workspace: who changed settings, invited users, or modified automations, and when. Administrators can filter by user and action — invaluable when something “mysteriously” changed.

Media library

Developer → Media stores your uploaded images, videos, audio and documents in one place. Upload once and reuse the same file across campaigns, templates and automations — no re-uploading the same product photo every time.

API tokens

Integrate WhatsMine with your own systems through the API:

1

Open Developer → API Tokens and click New Token.

2

Name it after its purpose (e.g. “website-forms”) and create it.

3

Copy the token immediately — it's shown only once. Store it safely.

4

Send it as a bearer token with API requests. Revoke any token from the same page if it's no longer needed.

⚠️ Tokens are passwords

Never commit tokens to public repositories or paste them in support chats. Revoke and re-create a token the moment you suspect exposure.

Webhooks

Developer → Webhooks pushes events from WhatsMine to your own endpoints — new message, contact created, order placed and more.

1

Add your endpoint URL and select the events to receive.

2

Save — events start POSTing to your URL as they happen.

3

Use the Deliveries view to inspect every attempt: payload, response code and retry state — this is where you debug a silent endpoint.

API documentation

Open Developer → API Docs for the full, in-app API reference — endpoints, parameters and examples using your own tokens. Developers should start there; this guide intentionally stays non-technical.
