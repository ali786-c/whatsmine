# WhatsMine homepage required pictures

This file defines the final picture set for the homepage. The inbox visual below the hero is reused from the existing product UI. Every other marketing picture should be freshly generated for WhatsMine so the page has one consistent visual direction.

## Global image direction

- Style: premium editorial SaaS marketing photography with natural people, realistic hands and believable workspaces.
- Palette: ivory, soft sage, forest green and small emerald/lime accents.
- Lighting: bright natural daylight with soft shadows.
- Composition: leave clean negative space for HTML headings and benefit chips; do not generate text inside the image.
- Output: high-resolution PNG or WebP, ideally 1600 x 1200 for feature images and 2000 x 1400 for wide panels.
- Avoid: stock-photo smiles, visible brand logos, fake UI text, watermarks, distorted hands, excessive neon, blue/purple backgrounds and duplicate poses.
- Every image needs an HTML alt description and lazy loading below the hero.

## Usage rule

One section gets one primary visual. A screenshot and a generated photo may appear together only when they explain different things: the photo shows the business outcome and the screenshot proves the product capability. Do not display multiple campaign, automation or template screenshots at full size in the same viewport.
