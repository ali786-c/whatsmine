1

Meta App Dashboard Setup

~10 min

1.1 Product Add Karo

  1. developers.facebook.com/apps → apna WhatsApp wala app kholo (naya mat banao)
  2. Left menu → Add Product → Facebook Login for Business → Set Up

1.2 Login Configuration Banao (Config ID)

  1. Left menu → Facebook Login for Business → Configurations → Create Configuration
  2. Name: Instagram Automation
  3. Yeh 5 permissions add karo:
pages_show_list pages_read_engagement instagram_basic instagram_manage_comments instagram_manage_messages
  1. Save → jo Config ID bane usse copy kar lo 📋
⚠️
Yeh Config ID WhatsApp wali config se BILKUL alag honi chahiye. Same di to Instagram login par WhatsApp permissions aayengi aur kaam nahi karega.

1.3 OAuth Redirect URIs (DONO add karo)

  1. Facebook Login for Business → Settings → Valid OAuth Redirect URIs mein yeh DONO lines add karo (exact — copy button use karo):
https://wa.careerinpak.com/app/instagram/setup
https://wa.careerinpak.com/app/inbox/setup
URIKaunsa button use karta hai
/app/instagram/setupInstagram → Connect (comment automation module)
/app/inbox/setupInbox → Setup → Connect Instagram (Inbox DMs)
⚠️
App Domains field akela kaafi NAHI hai — OAuth ke liye Valid OAuth Redirect URIs mein exact URI honi hi chahiye. Missing ho to Meta ka error aata hai: "Can't Load URL" ya "URL blocked — redirect URI is not white-listed".

1.4 App Mode

  1. Settings → Basic → upar toggle se app Live karo
  2. Agar Development pe rehna ho: jis Facebook account se connect karoge woh Roles → Admin/Developer mein hona chahiye
ℹ️
Apne accounts ke liye App Review ki zaroorat NAHI. Doosron ke (SaaS clients) accounts ke liye pehle App Review pass karna hoga (instagram_manage_comments + instagram_manage_messages Advanced Access hain).
🚫
Webhook Dashboard mein manually set NAHI karna. App khud register karti hai (unified registrar). Messenger → "Connected Tools" sirf tab jab Inbox mein IG DMs bhi chahiye.

3

VPS — Code Pull + Caches

~2 min
cd /www/wwwroot/wa.careerinpak.com

git pull origin master

php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan cache:clear

sudo systemctl restart php8.2-fpm 2>/dev/null || sudo systemctl restart php-fpm

npm / composer / migrate nahi karna — sab already done hai, built assets repo mein commit hain.

4

VPS — Queue Worker + Cron (ek dafa)

~5 min

4.1 Supervisor Worker (instagram queue)

Worker conf file kholo (naam different ho sakta hai):

nano /etc/supervisor/conf.d/laravel-worker.conf   # ls /etc/supervisor/conf.d/ se dekho

command= line aisi honi chahiye:

command=php /www/wwwroot/wa.careerinpak.com/artisan queue:work --queue=instagram,default --tries=3 --timeout=60 --sleep=3
sudo supervisorctl reread && sudo supervisorctl update && sudo supervisorctl restart all
🔥
Iske bina funnel kaam NAHI karega — webhook aayega magar jobs queue mein pending rahenge.

4.2 Scheduler Cron

crontab -l | grep schedule:run

Output nahi aya? crontab -e karke yeh line add karo:

* * * * * cd /www/wwwroot/wa.careerinpak.com && php artisan schedule:run >> /dev/null 2>&1

4.3 Quick Verify

php artisan route:list | grep instagram

curl "https://wa.careerinpak.com/webhooks/instagram/VERIFY_TOKEN?hub.mode=subscribe&hub.verify_token=VERIFY_TOKEN&hub.challenge=hello"

Curl ka response hello aana chahiye (VERIFY_TOKEN ki jagah apna admin panel wala token).
