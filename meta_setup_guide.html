6.1 Follow-Gate Loop — Real Follow Verification (User Profile API)

Gated automation user ke "yes"/keyword par andha trust nahi karti — DM reply milte hi Graph User Profile API se asli follow status check hota hai (is_user_follow_business). Meta ye field sirf tab deta hai jab user ne account ko DM kiya ho (consent) — aur funnel check exactly reply ke baad hi karta hai, to limitation khud satisfy ho jati hai.

User ki replyAPI verificationBot kya karta hai
Keyword (DONE)✅ follows = trueDelivery — link / file / text 🎯
yes / haan / ho gaya✅ follows = trueKeyword reminder — "Amazing! Just reply DONE..."
Kuch aur✅ follows = truePolite keyword nudge (budget se bounded)
Kuch bhi — chahe DONE hi kyun na ho❌ follows = false"It seems you are not following us yet!" — ask dobara (bounded); budget khatam → funnel close → Inbox agent handoff
Kuch bhi❓ unknown (consent error / network fail / field missing)Fail-open — normal behaviour, delivery kabhi block nahi hoti (lead safe)
🛡️
Design rules: (1) Loop hamesha bounded hai — INSTAGRAM_MAX_NUDGES (default 2) se; koi user bot ko infinite loop mein nahi phansa sakta. (2) Inconclusive check kabhi lead nahi rokega — sirf verified false hi delivery rokta hai. (3) Har check ka result audit log + dm.log mein (follow-status resolved / failing open).

DMs Sirf Manual queue:work Pe Aati Hain? — Worker Permanent Karo

~10 min

10.1 Masla Samjho

php artisan queue:work --stop-when-empty sirf ek dafa queue ki jobs utha kar band ho jata hai — is liye DM tabhi dikhti hai jab tu khud command chalaye. Permanent fix: Supervisor ek daemon chalata hai jo hamesha zinda rehta hai, crash pe khud restart hota hai, aur server reboot ke baad bhi khud start ho jata hai.

⚠️
Har deploy (git pull) ke baad php artisan queue:restart bhi chalana — workers purana code memory mein rakhte hain.

10.2 Supervisor Config Banao

Server pe config file kholo:

nano /etc/supervisor/conf.d/whatsmine-worker.conf

Aur ye paste karo:

[program:whatsmine-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /www/wwwroot/wa.careerinpak.com/artisan queue:work --queue=instagram,default --sleep=3 --tries=3 --timeout=120 --max-time=3600
autostart=true
autorestart=true
user=www
numprocs=2
redirect_stderr=true
stdout_logfile=/www/wwwroot/wa.careerinpak.com/storage/logs/worker.log
stopwaitsecs=3600

--queue=instagram,default — Instagram pehle serve hoti hai (DMs fast aati hain), default uske baad. numprocs=2 = do parallel workers.

ℹ️
aaPanel/BaoTa users: App Store → Supervisor plugin install karo → Add daemon → wahi command + numprocs=2 daalo — config file manually banane ki zaroorat nahi.
✅
Pehle se worker chal raha hai? (jaise --queue=whatsapp,broadcast,automation,social,leads,ai,default) — nayi config mat banao. Bas usi command ke --queue= ke shuru mein instagram, laga do (order = priority: Instagram pehle serve hoti hai) aur restart karo.

10.3 Start + Enable (Reboot-proof)

sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start all
sudo supervisorctl status

whatsmine-worker:00 aur whatsmine-worker:01 RUNNING dikhne chahiye. autostart=true ki wajah se server reboot ke baad bhi khud chalenge.

Instagram Login Migration — Meta Dashboard Setup (Detailed)

Sep 15, 2026

Ab Instagram sirf apni Instagram credentials se connect hota hai (Business Login for Instagram). Purana Facebook-Page wala connect flow code aur UI dono se hata diya gaya hai — agar koi account pehle FB-login se connected tha to usay ek dafa Connect with Instagram se dobara connect karo. WhatsApp ka Facebook-Login path bilkul untouched rahega (same Meta app). Messenger apne embedded-signup pe chalta rahega. Neeche poora Meta Dashboard setup step-by-step hai.

IG.1 Instagram Product Add Karo (agar pehle se nahi hai)

  1. developers.facebook.com kholo → apna app (wohi jispe WhatsApp chal raha hai) → App Dashboard mein jao.
  2. Left sidebar mein Add Product (ya “Products” header ke paas +) dhundo.
  3. Instagram card pe Set up click karo.
  4. Instagram product ke andar “API setup with Instagram login” option select karo (yehi naya setup hai — “API setup with Facebook login” nahi).

IG.2 Business Login Settings — App ID + Secret Copy Karo

  1. Left sidebar: Instagram → API setup with Instagram login kholo.
  2. Wahan 3–4 numbered sections honge — “3. Set up Instagram business login” tak scroll karo → Business login settings click karo.
  3. Is page pe top pe hi Instagram app ID (number, e.g. 1234567890) dikhega — copy karo.
  4. Instagram app secret ke paas Show click karo (apna FB password mangega) — copy karo.
  5. ⚠️ Ye alag hain WhatsApp wale App ID/Secret se — confuse mat hona. Purane wale WhatsApp ke liye waise hi rahenge.

IG.3 OAuth Redirect URI Add Karo (SAME Business login settings page pe)

Usi Business login settings page pe neeche Valid OAuth Redirect URIs section hai → Add URI → ye EXACT line paste karo (trailing slash nahi):

https://wa.careerinpak.com/app/instagram/setup
https://wa.careerinpak.com/app/inbox/setup
URIKaunsa button use karta hai

/app/inbox/setupInbox → Setup (Channels) drawer ka “Connect with Instagram”
⚠️
App Domains kaafi nahi hai — OAuth ke liye exact URI is list mein honi hi chahiye, warna Instagram login window pe “URL blocked — redirect URI is not white-listed” error aayega. Dono URIs add karo.

IG.4 Data Access — Advanced Access (sirf tab jab doosron ke accounts)

  1. Apne khud ke accounts connect karne ke liye Standard Access kaafi hai — App Review ki zaroorat NAHI. Aage barho IG.5 pe.
  2. SaaS clients ke accounts connect karne hain to: App Dashboard → App Review → Permissions and Features → instagram_business_basic, instagram_business_manage_messages, instagram_business_manage_comments ke liye Advanced Access request karo (App Review + Business Verification lagegi).
  3. App Live mode mein hona chahiye (Settings → Basic → toggle) jab real connects karne hon — Privacy Policy URL + Data Deletion callback mangega.

IG.5 App Panel Mein Credentials Paste Karo (2 min)

  1. Apna panel kholo → Admin → Integrations → Meta App.
  2. Naye fields mein paste karo: Instagram App ID + Instagram App Secret → Save.
  3. Purane fields (App ID, App Secret, Webhook Verify Token, Config ID waghaira) mat chhedo — WhatsApp unhi pe chal raha hai.
  4. (Optional, bina OAuth ke) Meta Dashboard ke usi “API setup with Instagram login” page pe “Generate token” button bhi hai — apne khud ke account ka 60-din token banata hai. Panel ke Instagram → Setup mein “manual token” field se wo bhi paste ho sakta hai.

IG.6 Client Connect + Test (2 min)

  1. Instagram → Setup ya Inbox → Setup (Channels) kholo — ab purple “Connect with Instagram” button dikhna chahiye.
  2. Click karo → Instagram ka apna login window khulega → Instagram username/password daalo (jo professional/business/creator account hai) → permissions Allow karo.
  3. Wapas redirect hoga aur connection khud save ho jayegi — Inbox DMs + comment automation ek hi connection se dono chalu. Facebook Page link karne ki zaroorat nahi.
  4. Facebook wala purana flow ab bhi drawer mein available hai — purane Page-linked accounts waise ke waise chalte rahenge.
  5. Test: doosre IG account se post pe comment karo → private-reply DM aani chahiye → reply karo → gate loop chalna chahiye.

IG.7 Verify — Diagnose + Token Expiry

  1. php artisan instagram:diagnose chalao — naya “Instagram Login readiness” section dekho:
  2. [ OK ] Instagram App ID configured → IG.5 sahi hua
  3. [ OK ] Instagram-Login accounts: N + token valid for X days → connect + token fine
  4. [ FAIL ] token EXPIRED → bas dobara “Connect with Instagram” karo (ya manual token paste karo)
🔄
60-day tokens (naya system): Facebook Page token kabhi expire nahi hota tha, Instagram-Login token 60 din ka hota hai. System daily raat 2:30 baje refresh job chalata hai jo expiry se pehle naya 60-day token le aata hai — tab tak sab automatic. Sirf cron + worker zinda rakhna (jo pehle se hain).
✅
Webhooks bilkul waise hi automatic hain: connect hote hi system khud Meta ko callback + fields register karta hai (pehle jaisa) — dashboard mein manually kuch nahi karna. Comments, DMs, postbacks sab pehle ke jaise hi aayenge; naye flow mein sirf host graph.instagram.com hai aur koi Facebook Page nahi.
